URL: cargando...

⚠️ Estás usando el sistema como archivo local (file://)

Para que el celular acceda al menú, necesitas un servidor web local. Sigue estos pasos:

  1. Abre CMD (Símbolo del sistema)
  2. Ve a tu carpeta del proyecto:
    cd C:\ruta\a\tu\proyecto
  3. Ejecuta:
    python -m http.server 8080
  4. Abre en tu PC: http://localhost:8080/index.html
  5. Conecta el celular a la misma red WiFi
  6. Escribe ipconfig en CMD para ver tu IP (ej: 192.168.1.5)
  7. Regresa aquí y haz clic en Regenerar QR ✅

📖 Instrucciones

  1. 📱 Abre la cámara de tu celular
  2. 🔲 Escanea el código QR de la izquierda
  3. 🍽️ Los clientes verán todo el menú con precios
  4. ➕ Seleccionan los platos que desean
  5. 🪑 Eligen su número de mesa
  6. ✅ Confirman el pedido
  7. 🔔 El pedido llegará aquí como notificación
